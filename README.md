# 🎵 sistema-musical-Danilo-Oliveira

> **Sprint 1 — Interface e Front-End**
> 
> Projeto acadêmico de um sistema de gerenciamento de acervo musical (Artistas, Músicas e Biblioteca), desenvolvido em HTML5 e CSS3 responsivo.

---

## 📌 Sobre o Projeto

O **Sistema Musical** é uma aplicação web desenvolvida para permitir o cadastro, a organização e a visualização de artistas e de suas respectivas músicas. Nesta primeira fase (**Sprint 1**), o foco principal foi a criação de uma **interface visual amigável (UI)**, navegação intuitiva e estrutura limpa do HTML5/CSS3.

O projeto foi construído preparando os formulários e campos de entrada para a futura integração com **PHP** e **Banco de Dados (MySQL)** na **Sprint 2**.
